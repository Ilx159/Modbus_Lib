# Modbus_Lib
Projeto com o intuito de aprender o funcionamento de protocolos.

### Objetivo
O principal objetivo é fazer uma conexão estável com um CLP (Controlador Lógico Programavel) utilizando somente C e suas bibliotecas.

### Futuro

Futuramente desejo fazer uma interface para conexões serial e também uma interface para programar o CLP usando C (como se fosse um editor de texto).
